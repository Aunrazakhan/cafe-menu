## Project Overview
This project is a multi-page web application built for a café menu theme. It demonstrates structured HTML5 markup, customized CSS styling, dynamic JavaScript user interactions, and page navigation.

- **Theme:** Café Menu Website (Chai Corner)
- **Live Demo:** [https://aunrazakhan.github.io/cafe-menu](https://aunrazakhan.github.io/cafe-menu)
- **AI Tool Used:** Gemini

---

## Project Structure & Pages

1. `index.html` — **Home Page**
   - Main header, café image, featured menu preview, and order trigger button.
2. `menu.html` — **Menu Page**
   - Categorized food & beverage items (Beverages, Bakery, Desserts) with price lists, product images, and "Add to Cart" alert functionality.
3. `contact.html` — **Contact Page**
   - Café address, phone details, operating hours, and an interactive feedback submission form.
4. `style.css` — **Stylesheet**
   - Unified color palette (`#2D3B36` background, `#8D4925` primary accents), container cards, tables, and typography across all pages.

---

## Technologies Used
- **HTML5:** Semantic layout elements, forms, and tables.
- **CSS3:** Styling, custom color schemes, border radius, and container layout.
- **JavaScript:** Client-side alerts and form handling.
